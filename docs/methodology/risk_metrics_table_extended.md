## Core Metrics

| Metric | What it measures | Input | Formula | Interpretation |
|---|---|---|---|---|
| **Volatility** | Total price fluctuation (up and down) around the average return | Daily log returns of the stock, `r_t = ln(P_t / P_{t-1})` | `σ_daily = √[ Σ(r_t − r̄)² / (N−1) ]`<br>`σ_annual = σ_daily × √252` | Higher = more variable returns and a less stable ride.<br>Below 15% low, 15–25% moderate, 25–40% high, above 40% very high.<br>Compare against the benchmark and same-sector peers. |
| **Beta (β)** | Systematic (market) risk: how much the stock moves when the market moves | Stock returns and benchmark returns (e.g., S&P 500), same dates and frequency | `β = Cov(r_stock, r_market) / Var(r_market)`<br>Equivalent: `β = ρ × (σ_stock / σ_market)` | β = 1 moves with the market.<br>β above 1 amplifies market moves (aggressive).<br>β between 0 and 1 is defensive.<br>β near 0 is uncorrelated with the market.<br>β below 0 moves opposite to the market.<br>Report R² beside it to show how much of the stock's variance the market explains. |
| **Max Drawdown (MDD)** | Worst peak-to-trough loss in the period, the worst case for a buy-at-peak investor | Adjusted close prices | `Peak_t = max(P_s), s ≤ t`<br>`DD_t = P_t / Peak_t − 1`<br>`MDD = min(DD_t)` | The largest historical decline: 0 to −10% is normal noise, −20% or worse is bear-market level, worse than −50% is severe.<br>Recovery needs `1/(1+DD) − 1`: a −50% loss needs +100% to break even.<br>Also report the peak date, trough date, and recovery time. |
| **Sharpe Ratio** | Excess return earned per unit of total risk | Daily returns plus the risk-free rate (e.g., 3-month T-Bill) | `Sharpe = (R_p − R_f) / σ_p`<br>Annualized: `mean(r − rf_daily) / std(r − rf_daily) × √252` | Risk-adjusted return, higher is better.<br>Below 0 means it underperformed the risk-free rate.<br>0.5–1 is acceptable, 1–2 is good, above 2 is very good, and above 3 is suspicious.<br>Treats upside volatility as risk too. |
| **VaR (Value at Risk)** | Estimated maximum loss at a given confidence level over a given horizon, under normal market conditions | Daily returns, a confidence level (95% or 99%), and a horizon (1 day) | **Historical:** `−Percentile(returns, 1−α)`<br>**Parametric:** `−(μ + z × σ)`, with z = −1.645 at 95% and −2.326 at 99%<br>**Monte Carlo:** `−Percentile(simulated returns, 1−α)` | Estimated downside threshold. A 1-day 95% VaR of 2.5% means that on 95% of days the loss should not exceed 2.5%, and on about 1 day in 20 it should be worse.<br>It doesn't show how bad the loss is beyond the threshold (that's Expected Shortfall). |

## Additional Metrics

| Metric | What it measures | Input | Formula | Interpretation |
|---|---|---|---|---|
| **Expected Shortfall (CVaR)** | Average loss on the days when the loss exceeds VaR (tail severity) | Daily returns and a confidence level (95% or 99%) | `ES_α = −E[ r \| r ≤ −VaR_α ]`<br>Historical: average of all returns at or below the (1−α) percentile, sign flipped | Always ≥ VaR. A large gap between ES and VaR means heavy tails (rare but severe losses).<br>Answers "when we breach VaR, how bad is it on average?"<br>Preferred over VaR by regulators (Basel III) because it captures tail size. |
| **Correlation** | How strongly two assets' returns move together | Aligned daily returns of two stocks (or a stock and a sector) | `ρ(a,b) = Cov(r_a, r_b) / (σ_a × σ_b)`<br>Range: −1 to +1 | 0.8 to 1 very high, little diversification.<br>0.5 to 0.8 moderate to high.<br>0.2 to 0.5 moderate, useful diversification.<br>Near 0 low, strong diversification.<br>Below 0 natural hedge.<br>Correlations tend to rise toward 1 in market crises, so compare calm vs stress periods. |
| **Downside Deviation** | Volatility of bad returns only (below a minimum acceptable return) | Daily returns and a MAR (0 or the daily risk-free rate) | `DD = √[ (1/N) × Σ min(r_t − MAR, 0)² ]`<br>Annualized: `DD × √252` | Lower is better. Unlike volatility, it ignores upside moves.<br>If it is much smaller than total volatility, most of the variability is upside. |
| **Sortino Ratio** | Excess return per unit of downside risk | Daily returns, MAR, and downside deviation | `Sortino = (R_p − MAR) / DD`<br>Annualized: `mean(r − MAR) / DD × √252` | Higher is better, read like Sharpe (above 1 good, above 2 very good).<br>Sortino much higher than Sharpe means volatility is mostly upside.<br>Sortino close to or below Sharpe means returns are hurt by frequent downside moves. |
| **Calmar Ratio** | Annual return per unit of worst drawdown | Adjusted close prices (for CAGR and MDD) | `Calmar = CAGR / \|MDD\|`<br>`CAGR = (P_end / P_start)^(1/years) − 1` | Above 1 is good, above 3 is excellent, below 0.5 is weak.<br>Reflects what investors actually feel (drawdowns) rather than day-to-day volatility.<br>Sensitive to the single worst episode in the sample. |
| **Skewness** | Asymmetry of the return distribution | Daily returns | `Skew = E[(r − μ)³] / σ³` | Negative = larger and more frequent crashes than rallies (typical for equities).<br>Positive = occasional large upside jumps.<br>Near 0 = roughly symmetric.<br>Negative skew means Sharpe and parametric VaR understate risk. |
| **Excess Kurtosis** | Tail thickness compared with a normal distribution | Daily returns | `Kurt_excess = E[(r − μ)⁴] / σ⁴ − 3` | 0 = normal tails.<br>Above 0 = fat tails (extreme days happen more often than a normal model predicts). Daily stock returns are typically well above 0.<br>Justifies using Historical VaR and ES instead of Gaussian VaR.<br>Confirm with the Jarque–Bera normality test. |
| **Composite Risk Score** | One relative risk ranking per stock across the selected set | Volatility, \|MDD\|, VaR 95%, Beta for all selected stocks | `Score = 100 × [ 0.30·rank(Vol) + 0.30·rank(\|MDD\|) + 0.25·rank(VaR95) + 0.15·rank(β) ]`<br>`rank` = percentile rank (0 to 1), higher = riskier | 0–25 low, 25–50 moderate, 50–75 elevated, 75–100 high.<br>Relative to the chosen stocks only, so it changes if stocks are added or removed.<br>Weights are an adjustable assumption. Show it next to the raw metrics, never instead of them. |
